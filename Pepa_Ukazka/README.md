# Maturitní projekt: Pepa Ukázka

## Téma
_Doplň: o čem je hra/aplikace, krátký popis._

## Technologie
- Hra: _(např. Python 3 + Pygame)_
- Web: _(např. HTML, CSS, PHP)_
- Databáze: _(MySQL na dbs.spskladno.cz / SQLite)_

## Spuštění
1. `pip install -r requirements.txt`
2. Doplň údaje k databázi v `db_config.py`
3. Vytvoř databázi: `databaze/schema.sql` a pak `databaze/data.sql`
4. Hra: `python hra/main.py`
5. Web: _(doplň)_
6. Testy: `pytest tests`
