# Prezentace – KopačkyShop

## 1. Problém
Lidé potřebují najít kopačky pro správný povrch a velikost.

## 2. Řešení
Jednoduchý e-shop se seznamem produktů, košíkem a objednávkou.

## 3. Cílová skupina
Hráči fotbalu a futsalu.

## 4. Technologie
HTML, CSS, Flask a SQLite.

## 5. Ukázka
Předveď katalog → detail → košík → objednávku → změnu skladu v administraci.

## 6. Přínos
Propojení webu, backendu a databáze s kontrolou skladu.

## 7. Možnosti rozvoje
Vlastní fotografie, širší sortiment, lepší filtry.
