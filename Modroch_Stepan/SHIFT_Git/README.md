# SHIFT – školní webový projekt

Frontend katalogu: HTML, CSS a JavaScript.

- `index.html` – struktura stránky a katalog.
- `style.css` – vzhled webu.
- `script.js` – filtrování, vyhledávání a řazení.
- `obrazky/` – sem vlož obrázky používané v HTML.

Statickou verzi lze spustit otevřením `index.html`. Odkazy `/prihlaseni`, `/registrace`, `/admin` a `/kosik` jsou připravené adresy pro budoucí Flask routes. Sekce `O projektu` funguje jako odkaz na část stránky.

Jde o školní demonstrační katalog, ne skutečný e-shop. Ceny, fotografie a dostupnost jsou ilustrační.
